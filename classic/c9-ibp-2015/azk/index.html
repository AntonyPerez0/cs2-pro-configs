These are AZK's CS:GO settings from 2014, the closest to January 2015 we found that can be converted (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 960p, AZK's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

The paste sets every setting that shapes this crosshair, including the iron-sight dot (CS2's defaults where their config has no value), so nothing from your current crosshair carries over.

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec azk-c9-ibp-2015 in the console.

Where these settings come from

  • Crosshair, viewmodel, HUD and radar · 2014 · confidence medium · github.com 1, 2, 3
    How the date is known

    A config.cfg written by AZK's game (in-game name 'kza'), from setup.gg's archive. It has cl_obs_interp_enable, the switch for the spectator-camera interpolation added on 8 Aug 2014, but not the music-volume settings added on 10 Oct 2014, so it was saved between those dates.

  • Sensitivity · 2014 · confidence medium · github.com 1, 2
    How the date is known

    Same game-written config.cfg as the crosshair (sensitivity 2, zoom ratio 1, raw input off), saved between 8 Aug 2014 (it has that update's spectator-interpolation switch) and 10 Oct 2014 (it lacks that update's music-volume settings).

  • DPI (same sensitivity) · 2016-12-13 · confidence medium · github.com 1, 2
    How the date is known

    setup.gg's profile for AZK (data.yml), added on 13 Dec 2016 and never changed, lists sensitivity 2, the same as the 2014 config, with 400 DPI at 1000 Hz and raw input off. It doesn't say when the values were collected, so this is the latest possible date.

  • Resolution · 2016-12-13 · confidence medium · github.com 1, 2
    How the date is known

    The same setup.gg profile, added on 13 Dec 2016 and never changed, lists 1280x960 at 4:3. It doesn't say when the values were collected, so this is the latest possible date.

DPI is only taken from a source that lists the same sensitivity, so the eDPI matches the sensitivity shown. The other parts can come from configs of different dates, as listed.
