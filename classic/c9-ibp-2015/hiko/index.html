These are Hiko's CS:GO settings from 2014, the closest to January 2015 we found that can be converted (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 960p, Hiko's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

Full config 4 parts

Download .cfg

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec hiko-c9-ibp-2015 in the console.

Where these settings come from

  • Crosshair, viewmodel, HUD and radar · 2014 · confidence medium · github.com 1, 2, 3
    How the date is known

    A config.cfg written by Hiko's game (in-game name 'Hiko <Logitech>'), from setup.gg's archive. Its Operation Breakout reminder stores a timestamp of 4 Aug 2014, and it lacks snd_menumusic_volume and the other music-volume settings added on 10 Oct 2014, so it was saved between those dates.

  • Sensitivity · 2014 · confidence medium · github.com 1, 2, 3
    How the date is known

    Same game-written config.cfg as the crosshair (sensitivity 4, zoom ratio 1, raw input on), saved between 4 Aug 2014 (its Operation Breakout reminder timestamp) and 10 Oct 2014 (the music-volume settings it lacks).

  • Resolution · 2016-12-13 · confidence medium · github.com 1, 2
    How the date is known

    From setup.gg's profile for Hiko (data.yml), published on 13 Dec 2016 and not changed since. It doesn't say when the values were collected, so this is the latest possible date.

DPI is only taken from a source that lists the same sensitivity, so the eDPI matches the sensitivity shown. The other parts can come from configs of different dates, as listed.
