These are olofmeister's CS:GO settings from 2015-09-21, the year of the ranking (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 768p, olofmeister's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

Full config 2 parts

Download .cfg

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec olofmeister-2015 in the console.

Mouse & Sensitivity sensitivity

DPI & polling rate are set in your mouse software, not in-game. Recommended: DPI 400 · eDPI 680 · polling 1000 Hz
