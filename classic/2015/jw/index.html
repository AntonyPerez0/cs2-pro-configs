These are JW's CS:GO settings from 2014, the closest to 2015 we found that can be converted (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 768p, JW's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

Full config 3 parts

Download .cfg

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec jw-2015 in the console.

Where these settings come from

  • Crosshair, viewmodel, HUD and radar · 2014 · confidence medium · github.com 1, 2, 3
    How the date is known

    Dated from evidence inside the file. The commit (setupgg/csgo a7612a6, 2016-04-29 08:50 +0200) only shows when it was uploaded, and setupgg replaced it with the 2013 file later that day. A client wrote this config.cfg between 2014-08-09 and about 2014-11-11. Lower bound: cl_operation_premium_reminder_breakout is "1407590090", which is 2014-08-09 13:14:50 UTC. The file also has cl_crosshairgap_useweaponvalue (added 2014-08-01), plus engine_no_focus_sleep and cl_radar_square_with_scoreboard (both added 2014-07-23). Upper bound: it has no cl_operation_premium_reminder_op05. Every config in the same pack holds only one operation-reminder cvar. The Breakout ones carry timestamps from 2014-07-02 to 2014-08-09. The op05 ones carry timestamps from 2014-11-19 (daps, 1416402469) onward. Operation Vanguard launched in the 2014-11-11 update notes. The file also lacks cl_crosshair_sniper_width, which was added on 2016-01-20.

  • Resolution · 2016-12-13 · confidence low · github.com 1, 2
    How the date is known

    This is the GitHub commit date of player/jw/data.yml in setupgg/data (initial commit afdec47, 2016-12-13 17:37 +0200), and the file is unchanged since. It is only an upper bound. The sheet gives 'team: fnatic', but the team history on Liquipedia has JW at GODSENT from 2016-08-15 to 2017-02-04. So the data were already out of date when committed and were probably collected while he was still at fnatic, before 2016-08-15.

Settings from different sources are only combined when they agree (DPI is only paired with a sensitivity from the same source), so the eDPI never mixes eras.
