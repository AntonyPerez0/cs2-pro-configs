  • Old style 5 (Legacy) placed its bars at round(4 × height / 1200 + gap) at rest instead of Static Cross's trunc(4 + gap); at 720 that is 1 instead of 3 pixels, a reading of the old source that is unverified in the pre-update game.
  • Rounding and dropping the fraction give your old size or thickness different whole pixels; the converter rounds, as other converters and community measurements do, so the old game may have drawn it 1 px smaller.
  • Exported style 5 keeps the old style family. Its at-rest shape is assumed to match Static Cross, but it moves with inaccuracy and shots, which is neither modelled nor checked in game.

These are pashaBiceps's CS:GO settings from 2014, the year of the ranking (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 720p, pashaBiceps's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec pashabiceps-2014 in the console.

Where these settings come from

  • Crosshair, viewmodel, HUD and radar · 2014 · confidence low · github.com 1, 2, 3
    How the date is known

    No source gives this config a date. The latest possible date is 2016-04-29, when setupgg/csgo commit a7612a6 (Nic Malan, 'Init') first added pasha/config.cfg. The later copies at players/pasha/config.cfg (2016-07-17) and setupgg/data player/pasha/config/config.cfg (2016-12-14) have the same values; only the case of key names changed. The year comes from which cvars the file contains, checked against Valve's release notes (ckreisl/cs-updates-as-json, data/csgo/updates_combined_raw.json, re-checked this session). The file includes cvars added on 2014-02-12 (the cl_crosshair_dynamic_split* family), 2014-02-20 (cl_color and the renamed cl_teammate_colors_show) and 2014-02-27 (spec_usenumberkeys_nobinds). It lacks cvars added on 2014-04-23 (cl_scoreboard_mouse_enable_binding), 2014-05-01 (cl_hud_*), 2014-07-23 (cl_radar_square_with_scoreboard), 2014-08-01 (cl_crosshairgap_useweaponvalue) and 2016-01-20 (cl_crosshair_sniper_width). Other setupgg config.cfg files (neo, gmx, taz, rubino) do contain cl_scoreboard_mouse_enable_binding and cl_hud_color, so the game does write those to config.cfg. A scan of every cvar in the file found none that Valve's notes introduce after 2014-02-27. So the game last wrote this file between 2014-02-27 and 2014-04-23. The exception is cl_crosshairstyle "5": Valve's 2014-07-16 notes say they 'added a 6th crosshair style (cl_crosshairstyle 5)'. That value either was accepted before it was announced, or was edited into the file later. Four setupgg configs have style 5 with a cvar set from before 2014-07-16: pasha, neo (between 2014-04-23 and 2014-05-01), moe and schneider (both before 2014-02-12). So the cause looks systematic, not specific to pasha. Read the date as 'about early-to-mid 2014'. The crosshair style line may be from July 2014 or later.
