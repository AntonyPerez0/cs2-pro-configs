These are KRiMZ's CS:GO settings from 2014, the year of the ranking (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 1024p, KRiMZ's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

Full config 3 parts

Download .cfg

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec krimz-2014 in the console.

Where these settings come from

  • Crosshair, viewmodel, HUD and radar · 2014 · confidence medium · github.com 1, 2
    How the date is known

    Game-written config.cfg from setup.gg's archive. It has cl_crosshairgap_useweaponvalue (added 1 Aug 2014) but not the music-volume settings added on 10 Oct 2014, so it was saved between those dates. His autoexec.cfg from the same upload sets the same crosshair.

  • Sensitivity · 2014 · confidence medium · github.com
    How the date is known

    From the same game-written config.cfg as the crosshair, which has cl_crosshairgap_useweaponvalue (added 1 Aug 2014) but not the music-volume settings added on 10 Oct 2014, so it was saved between those dates.

  • Resolution · 2016-12-13 · confidence low · github.com
    How the date is known

    setup.gg's profile for KRIMZ (data.yml), added to its data repository on 13 Dec 2016 and never changed. It doesn't say when the settings were collected, and its sensitivity (1.8) differs from the 2014 config's 1.3, so its DPI isn't used.

  • Photo · IEM Season X World Championship (Katowice 2016) · 2016-03-06 · by VaKarM · CC BY 3.0 · via Wikimedia Commons

DPI is only taken from a source that lists the same sensitivity, so the eDPI matches the sensitivity shown. The other parts can come from configs of different dates, as listed.
