  • Not in this config because the setting didn't exist yet, so off: cl_crosshairgap_useweaponvalue, cl_crosshair_t, cl_crosshair_recoil.
  • Old style 5 (Legacy) placed its bars at round(4 × height / 1200 + gap) at rest instead of Static Cross's trunc(4 + gap); at 600 that is 2 instead of 3 pixels, a reading of the old source that is unverified in the pre-update game.
  • Odd-width bars sit on a different centre pixel in the new game, so the crosshair may appear 1 px off.
  • Old thickness 0 still drew a thin line, so the export uses a positive thickness.
  • Exported style 5 keeps the old style family. Its at-rest shape is assumed to match Static Cross, but it moves with inaccuracy and shots, which is neither modelled nor checked in game.

NEO played CS 1.6 in 2011, so these are their CS:GO settings from 2014-04, the closest to 2011 we found that can be converted (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 600p, NEO's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

The paste sets every setting that shapes this crosshair, including the iron-sight dot (CS2's defaults where their config has no value), so nothing from your current crosshair carries over.

Download .cfg

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec neo-2011 in the console.

Where these settings come from

  • Crosshair, viewmodel, HUD and radar · 2014-04 · confidence low · github.com 1, 2
    How the date is known

    A full config.cfg in the game's own format, from setup.gg's archive (uploaded 29 Apr 2016). It has the scoreboard-mouse setting added 23 Apr 2014 but none of the cl_hud_* settings added 1 May 2014, so it was saved in late April 2014. Its crosshair style 5 was only added on 16 Jul 2014, so that line may be later.

  • Sensitivity · 2014-04 · confidence medium · github.com 1, 2
    How the date is known

    Same config.cfg as the crosshair. It has the scoreboard-mouse setting added 23 Apr 2014 but none of the cl_hud_* settings added 1 May 2014, so it was saved in late April 2014.

  • Resolution · 2016-12-13 · confidence medium · github.com 1, 2
    How the date is known

    Player profile (data.yml) in setup.gg's GitHub data, first committed on 13 Dec 2016 and unchanged since. That is the latest date the settings can be from; the profile does not say when they were recorded.

  • DPI (assumed) · 2016-12-13 · github.com
    Why it is assumed

    No source lists a DPI with this sensitivity, so the DPI matcher assumes the 400 DPI of their setup.gg profile, which lists sensitivity 1.95; change it on the page if you know better.
