GeT_RiGhT played CS 1.6 in 2011, so these are their CS:GO settings from 2012-08, the closest to 2011 we found that can be converted (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 960p, GeT_RiGhT's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922); for Static Cross at 1080p and 960p it agrees with the rule crosshairrestore.com measured from in-game screenshots (CS2 builds before Sept 30), and nothing else has been checked against captures.

The paste sets every setting that shapes this crosshair, including the iron-sight dot (CS2's defaults where their config has no value), so nothing from your current crosshair carries over.

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec get-right-2011 in the console.

Where these settings come from

  • Crosshair · 2012-08 · confidence medium · github.com 1, 2
    How the date is known

    Game-written config.cfg (name 'NiP-GeT_RiGhT-A-') from setup.gg's archive, the same file as the sensitivity. Its medal-stats timestamp is 14 Aug 2012 and it lacks cl_crosshairgap, which the 22 Aug 2012 update added, so it was saved between those dates. It is also older than cl_crosshairstyle: instead it has sfcrosshair 0 (the classic crosshair) and cl_dynamiccrosshair 0 (no widening when moving). Style 4 (Classic Static) and gap 0 are mapping choices for that; with size 0 and the dot on, the old game drew only the dot, so neither changes how it looks.

  • Sensitivity · 2012-08 · confidence medium · github.com 1, 2
    How the date is known

    Game-written config.cfg (name 'NiP-GeT_RiGhT-A-') from setup.gg's archive. Its medal-stats timestamp is 14 Aug 2012 and it lacks cl_crosshairgap, which the 22 Aug 2012 update added, so it was saved between those dates.

  • DPI (same sensitivity) · 2016-12-13 · confidence low · github.com

    setup.gg's player profile, created in setupgg/data's first commit on 13 Dec 2016 and never changed. It lists the same sensitivity (2.9) with 400 DPI at 500 Hz but gives no date or source, so this is only when it was published.

    How the date is known
