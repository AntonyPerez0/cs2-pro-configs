markeloff played CS 1.6 in 2011, so these are their CS:GO settings from 2023-01-20, the closest to 2011 we found that can be converted (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 768p, markeloff's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

Full config 2 parts

Download .cfg

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec markeloff-2011 in the console.

Where these settings come from

  • Crosshair · 2023-01-20 · confidence low · github.com, liquipedia.net
    How the date is known

    Liquipedia's 'Updated as of 2023-01-20 (275 days ago)' label. It appears on all four tables of markeloff's page: Mouse Settings (Advanced and Simple), Hardware and Crosshair Settings. The page was read from a copy Liquipedia's parser saved at 20231022123007, revision id 2624115; 2023-01-20 plus 275 days is 2023-10-22, which matches. That copy is scraper-cache/players/markeloff.html in scraper-cache.zip in Lindeneg/csgo-pro-settings. The zip was added in commit ddf05eb on 2023-10-26 and is unchanged at HEAD f6fe6bd. Only 5 of the cached player pages carry the date 2023-01-20, so it is the date of a single-page edit and not a bulk template change. The page text describes him as a Counter-Strike: Global Offensive player, and the crosshair code is the old CS:GO 'CSGO-' format (version byte 1), so this is a CS:GO config.
