These are GeT_RiGhT's CS:GO settings from 2014-10-11, the closest to 2013 we found that can be converted (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 960p, GeT_RiGhT's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922); for Static Cross at 1080p and 960p it agrees with the rule crosshairrestore.com measured from in-game screenshots (CS2 builds before Sept 30), and nothing else has been checked against captures.

The paste sets every setting that shapes this crosshair, including the iron-sight dot (CS2's defaults where their config has no value), so nothing from your current crosshair carries over.

Download .cfg

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec get-right-2013 in the console.

Where these settings come from

  • Crosshair · 2014-10-11 · confidence low · steamcommunity.com
    How the date is known

    Size 5, Classic Static (style 4), thickness 1.15 and green (colour 1) are from a reply posted on 11 Oct 2014 in a Steam forum thread that lists his settings; the same poster then points to NiP's team page (nip.gl/csgoteam) for more. The post gives no gap or alpha; those, and the outline off, come from Liquipedia's crosshair table of 20 Feb 2016 (see below), which agrees with everything the post gives.

  • Crosshair gap and alpha (and outline off) · 2016-02-20 · confidence low · liquipedia.net 1, 2
    How the date is known

    Liquipedia's GeT_RiGhT page got its first crosshair table in revision 304993 on 20 Feb 2016: style 4, size 5, thickness 1.15, gap -1, dot 0, colour 1, alpha 200 and outlinethickness 0, read here as the outline off. The table cites no source and was unchanged in Feb 2017 (revision 575941). Only its gap, alpha and outline are used, because the 2014 post doesn't give them; they may differ from what he used in 2014.

  • Sensitivity · 2012-08 · confidence medium · github.com 1, 2
    How the date is known

    Game-written config.cfg (name 'NiP-GeT_RiGhT-A-') from setup.gg's archive. Its medal-stats timestamp is 14 Aug 2012 and it lacks cl_crosshairgap, which the 22 Aug 2012 update added, so it was saved between those dates.

  • DPI (same sensitivity) · 2016-12-13 · confidence low · github.com
    How the date is known

    setup.gg's player profile, created in setupgg/data's first commit on 13 Dec 2016 and never changed. It lists the same sensitivity (2.9) with 400 DPI at 500 Hz but gives no date or source, so this is only when it was published.

  • Resolution · 2016-12-13 · confidence low · github.com
    How the date is known

    setup.gg's player profile (1280x960, 4:3), created in setupgg/data's first commit on 13 Dec 2016 and never changed. It gives no date or source, so this is only when it was published.

DPI is only taken from a source that lists the same sensitivity, so the eDPI matches the sensitivity shown. The other parts can come from configs of different dates, as listed.
