These are GuardiaN's CS:GO settings from 2022-04-30, the closest to 2013 we found that can be converted (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 600p, GuardiaN's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

Where these settings come from

  • Crosshair · 2022-04-30 · confidence medium · github.com, liquipedia.net
    How the date is known

    Liquipedia's 'Updated as of 2022-04-30' stamp on the Crosshair Settings box. The box cites a FACEIT competitive match dated 2022-04-30 (www.faceit.com/en/csgo/room/1-fdbc3d94-fb03-43db-92ba-23337c72b473, a link I confirmed in the snapshot HTML). I re-read it from the same cached Liquipedia snapshot (Lindeneg scraper-cache.zip, 2023-10-22).

  • Sensitivity · 2014-07 · confidence medium · github.com 1, 2, 3
    How the date is known

    Dated from the file's contents. The file is a game-written config.cfg, first committed to setupgg/csgo in commit e03e8c36 on 2016-04-29 (re-checked in a full-history clone). It contains engine_no_focus_sleep and cl_radar_square_with_scoreboard, which Valve added on 23 Jul 2014 (blog.counter-strike.net/index.php/2014/07/9942/). It also contains cl_operation_premium_reminder_breakout; the name points to Operation Breakout, which began on 1 Jul 2014 (blog .../2014/07/9819/). It lacks cl_crosshairgap_useweaponvalue, added on 1 Aug 2014 (blog .../2014/08/10023/). Both of those cvars are ARCHIVE in itorr's commands.csv, and the game writes every ARCHIVE cvar to config.cfg. That puts the save between 23 Jul and 1 Aug 2014. I also checked every cvar in the file against all Valve release notes. Every later mention (cl_timeout 2016, snd_legacy_surround 2017, zoom_sensitivity_ratio_* 2016/2018, and others) changes an existing cvar rather than adding one, so nothing in the file contradicts the window. Among ARCHIVE cvars missing from the file, the only one Valve's notes add before Sep 2014 is cl_crosshairgap_useweaponvalue. Liquipedia's team history puts him on Natus Vincere from 2013-12-09 to 2017-07-28.

  • DPI (same sensitivity) · 2016-12 · confidence low · github.com 1, 2
    How the date is known

    This is an upper bound only. The profile is in setupgg/data's first commit, afdec47f, dated 2016-12-13 (re-checked). That is when setupgg recorded it; when the settings were measured is not stated. The day-level date 2016-12-13 was changed to 2016-12 so the date does not imply that he used these settings on that day.

  • Resolution · 2016-12 · confidence low · github.com 1, 2
    How the date is known

Settings from different sources are only combined when they agree (DPI is only paired with a sensitivity from the same source), so the eDPI never mixes eras.
