  • Not in this config, so off, as CS:GO had it by default: cl_crosshairgap_useweaponvalue, cl_crosshair_t.
  • cl_crosshair_recoil was cheat-protected in CS:GO, so off.
  • Odd-width bars sit on a different centre pixel in the new game, so the crosshair may appear 1 px off.
  • Old thickness 0 still drew a thin line, so the export uses a positive thickness.

These are GuardiaN's CS:GO settings from 2022-04-30, the closest to 2013 we found that can be converted (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 600p, GuardiaN's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

Full config 2 parts

Download .cfg

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec guardian-2013 in the console.

Where these settings come from

  • Crosshair · 2022-04-30 · confidence medium · github.com, liquipedia.net, faceit.com
    How the date is known

    From the Crosshair Settings table on GuardiaN's Liquipedia page (copy cached in Oct 2023), marked 'Updated as of 2022-04-30' and citing a FACEIT match played that day.

  • Sensitivity · 2014-07 · confidence medium · github.com
    How the date is known

    A config.cfg written by GuardiaN's game, from setup.gg's archive. It has engine_no_focus_sleep and cl_radar_square_with_scoreboard (added 23 Jul 2014) but not cl_crosshairgap_useweaponvalue (added 1 Aug 2014), so it was saved between those dates.

  • DPI (same sensitivity) · 2016-12-13 · confidence low · github.com
    How the date is known

    From setup.gg's profile for GuardiaN (data.yml), published on 13 Dec 2016 and not changed since. It doesn't say when the values were collected, so this is the latest possible date. Its sensitivity, 1.3, is the same as in the July 2014 config.

  • Resolution · 2016-12-13 · confidence low · github.com
    How the date is known

    From setup.gg's profile for GuardiaN (data.yml), published on 13 Dec 2016 and not changed since. It doesn't say when the values were collected, so this is the latest possible date.

DPI is only taken from a source that lists the same sensitivity, so the eDPI matches the sensitivity shown. The other parts can come from configs of different dates, as listed.
