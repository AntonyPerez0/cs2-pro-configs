These are Hiko's CS:GO settings from 2014, the closest to 2013 we found that can be converted (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 960p, Hiko's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

Full config 4 parts

Download .cfg

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec hiko-2013 in the console.

Where these settings come from

  • Crosshair, viewmodel, HUD and radar · 2014 · confidence medium · github.com 1, 2, 3
    How the date is known

    Inferred from the file's contents and narrowed during verification to between 2014-08-04 and 2014-10-10. (1) Lower bound: cl_operation_premium_reminder_breakout = 1407110934 is 2014-08-04 00:08:54 UTC. The file also has cl_crosshairgap_useweaponvalue (update notes 2014-08-01: 'Added cl_crosshairgap_useweaponvalue convar') plus engine_no_focus_sleep and cl_radar_square_with_scoreboard (both added 2014-07-23). (2) Upper bound: the 2014-10-10 update notes say 'Added music volume controls for ... Main Menu, Round Start, Round End, Map objective, Ten Second Warning, Death Camera'. Seven other config.cfg dumps in the same setupgg commit (Xyp9x, cajunb, dennis, flamie, karrigan, olofmeister, pyth) contain the matching cvars snd_menumusic_volume, snd_roundstart_volume, snd_roundend_volume, snd_mapobjective_volume, snd_tensecondwarning_volume and snd_deathcamera_volume. Several have them at the default '1.0', which shows the game writes them automatically. The configs with operation-reminder timestamps from 2015 (op05 = 1420402680 = 2015-01-04 and 1424400283 = 2015-02-20) have them. All 8 dumps with Breakout timestamps from July or August 2014, Hiko's among them, lack them. Hiko's file has none of the six and only the older single snd_musicvolume. So it was saved by a client from before the 2014-10-10 update. The file was first committed on 2016-04-29 (setupgg/csgo e03e8c3).
