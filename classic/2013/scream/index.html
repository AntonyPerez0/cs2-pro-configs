  • Not in this config because the setting didn't exist yet, so off: cl_crosshairgap_useweaponvalue, cl_crosshair_t, cl_crosshair_recoil.
  • cl_crosshairalpha 9999 is outside 0-255; the old game drew it as 255.
  • Old style 5 (Legacy) placed its bars at round(4 × height / 1200 + gap) at rest instead of Static Cross's trunc(4 + gap); at 768 that is 3 instead of 4 pixels, a reading of the old source that is unverified in the pre-update game.
  • Rounding and dropping the fraction give your old size or thickness different whole pixels; the converter rounds, as other converters and community measurements do, so the old game may have drawn it 1 px smaller.
  • Exported style 5 keeps the old style family. Its at-rest shape is assumed to match Static Cross, but it moves with inaccuracy and shots, which is neither modelled nor checked in game.

These are ScreaM's CS:GO settings from 2014, the closest to 2013 we found that can be converted (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 768p, ScreaM's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

The paste sets every setting that shapes this crosshair, including the iron-sight dot (CS2's defaults where their config has no value), so nothing from your current crosshair carries over.

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec scream-2013 in the console.
