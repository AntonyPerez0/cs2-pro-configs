These are JW's CS:GO settings from 2013, the year of the ranking (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 768p, JW's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

Full config 3 parts

Download .cfg

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec jw-2013 in the console.

Where these settings come from

  • Crosshair, viewmodel, HUD and radar · 2013 · confidence medium · github.com 1, 2, 3
    How the date is known

    Dated from evidence inside the file. The commit date (setupgg/csgo 747d894, 2016-04-29 21:57 +0200) only shows when it was uploaded. A CS:GO client last wrote this config.cfg between about 2013-09-19 and 2014-02-12, so most of the possible window falls in late 2013. Lower bound: player_competitive_maplist2 includes mg_de_cache. Cache is first named in the 2013-09-26 update notes, a week after the 2013-09-19 update let Operation Bravo Pass owners play workshop maps in Competitive. The file also has cl_crosshair_drawoutline and cl_crosshair_outlinethickness, which were added on 2013-05-22. Upper bound: it lacks the archived cl_crosshair_dynamic_* cvars added on 2014-02-12, which JW's 2014 file in the same repo has. It also lacks cl_show_clan_in_death_notice, which the 2014 file has. The 2014-02-05 notes add a Game Options setting to hide team tags in death notices, so the file is probably from before 2014-02-05, but the notes don't name the cvar. It also lacks cl_color and cl_teammate_colors_show (2014-02-20), spec_usenumberkeys_nobinds (2014-02-27), cl_scoreboard_mouse_enable_binding (2014-04-23) and the cl_hud_* cvars (2014-05-01). Update dates come from the official notes collected in ckreisl/cs-updates-as-json (data/csgo/updates_combined_custom.json).
