These are GeT_RiGhT's CS:GO settings from 2012-12-13, the year of the ranking (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 960p, GeT_RiGhT's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec get-right-2012 in the console.

Where these settings come from

  • Crosshair · 2012-12-13 · confidence low · github.com 1, 2, 3
    How the date is known

    This is the date the preset was documented, not a file the player saved. Preset 'nip_getright' (labelled 'NiP GeT_RiGhT' in index.php) is in Skarbo/CSGOCrosshair commit e569127 'First commit'. Its author and committer date are both 2012-12-13 16:12:46 +0100. The page in that commit already shows 'Version 0.6' with a changelog back to 0.2, so the preset may be older than the commit. I checked all 28 commits up to 69fe7d2 (2014-07-30): the core values never change. Only the outline fields (set to 0) were added on 2013-06-13.

  • Sensitivity · 2012 · confidence medium · github.com 1, 2, 3
    How the date is known

    Earliest possible date: the file contains player_medalstats_most_recent_time "1344978905", which decodes to 2012-08-14 21:15:05 UTC (checked with `date -u`), so it was saved on or after that day. Latest likely date: the file has no cl_crosshairstyle. In the same 19-config setupgg collection, every config with a 2013-2015 medal timestamp has cl_crosshairstyle (Snax 2013-01-13, flusha 2013-04-08, jw 2013-05-04, cajunb 2013-06-26, NEO 2013-08-26, krimz/pyth/olofmeister/dennis 2014, karrigan 2015). The only two others without it are f0rest (2012-08-11) and Xizt (2012-08-14). The Skarbo crosshair generator's first commit (2012-12-13) already writes cl_crosshairstyle and documents styles 0-4, so that cvar existed by 2012-12-13. That makes the save window roughly 2012-08-14 to 2012-12-13. The file was published on GitHub on 2016-04-29 (setupgg/csgo commit a7612a6, 'Init').

  • DPI (same sensitivity) · 2016-12-13 · confidence low · github.com
    How the date is known

    This is the date setupgg published its profile, not a date the player confirmed. player/get_right/data.yml was created in setupgg/data commit afdec47 'Initial' (author and committer date 2016-12-13 17:37:03 +0200) and never changed afterwards (git log shows only afdec47). setupgg gives no source or as-of date for these values.

  • Resolution · 2016-12-13 · confidence low · github.com
    How the date is known

    This is the date setupgg published its profile, not a date the player confirmed. player/get_right/data.yml was created in setupgg/data commit afdec47 'Initial' (author and committer date 2016-12-13 17:37:03 +0200) and never changed afterwards (git log shows only afdec47). setupgg gives no source or as-of date for these values.

Settings from different sources are only combined when they agree (DPI is only paired with a sensitivity from the same source), so the eDPI never mixes eras.
