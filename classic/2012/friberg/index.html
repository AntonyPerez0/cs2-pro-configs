Crosshair new system

1024p pixels, enlarged
cl_crosshairstyle 2; cl_crosshair_length 4; cl_crosshair_thickness 1; cl_crosshair_gap 5; cl_crosshairdot 0; cl_crosshair_t 0; cl_crosshair_drawoutline 0; cl_crosshair_recoil 0; cl_crosshaircolor_r 50; cl_crosshaircolor_g 250; cl_crosshaircolor_b 250; cl_crosshaircolor_a 255; cl_crosshair_screen_height 1024
  • Style 2 was the original classic crosshair until February 2014: it showed when you fired but not weapon accuracy (style 5 later recreated it). In CS2, style 2 is the later, accurate version, so it spreads more with movement and inaccuracy than this crosshair did.
  • Not in this config because the setting didn't exist yet, so off: cl_crosshair_drawoutline, cl_crosshairgap_useweaponvalue, cl_crosshair_t, cl_crosshair_recoil.
  • Odd-width bars sit on a different centre pixel in the new game, so the crosshair may appear 1 px off.
  • Exported style 2 keeps the old style family. Its at-rest shape is assumed to match Static Cross, but it moves with inaccuracy and shots, which is neither modelled nor checked in game.

These are friberg's CS:GO settings from 2012-12-13, the year of the ranking (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 1024p, friberg's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

Download .cfg

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec friberg-2012 in the console.

Where these settings come from

  • Crosshair · 2012-12-13 · confidence low · github.com 1, 2
    How the date is known

    Preset 'NiP friberg' in the first commit (13 Dec 2012) of Skarbo's CS:GO crosshair generator, a third-party tool; later commits never change its values. His own 2012 config (used for the sensitivity) has the same colour (4) and size (2), with thickness 0.52 and the dynamic crosshair on.

  • Sensitivity · 2012-08-11 · confidence medium · github.com 1, 2
    How the date is known

    His autoexec.cfg sets sensitivity 1.4 and ends with echo "Updated: 2012-08-11". His game-written config.cfg also has 1.4 and lacks cl_crosshairgap, added on 22 Aug 2012, so it is from before that date.

  • Resolution · 2016-12-13 · confidence medium · github.com
    How the date is known

    setup.gg's player profile (1280x1024, 5:4), created in setupgg/data's first commit on 13 Dec 2016 and never changed. It gives no date or source, so this is only when it was published.

  • Photo · DreamHack Winter 2013 · 2013-11 · by FlamingCowTV · CC BY 3.0 · via Wikimedia Commons · cropped

DPI is only taken from a source that lists the same sensitivity, so the eDPI matches the sensitivity shown. The other parts can come from configs of different dates, as listed.
