These are SmithZz's CS:GO settings from 2013, the closest to 2012 we found that can be converted (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 768p, SmithZz's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

Full config 3 parts

Download .cfg

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec smithzz-2012 in the console.

Where these settings come from

  • Crosshair, viewmodel, HUD and radar · 2013 · confidence medium · github.com 1, 2, 3
    How the date is known

    The file's first line reads '// VERYGAMES SmithZz - 04/01/2013'. I re-read it in setupgg/csgo commit e03e8c3 (2016-04-29, the file's first public appearance) and in setupgg/data HEAD. The day and month are ambiguous: it is 4 Jan 2013 if the date is DD/MM (the French convention, so the likelier reading) and 1 Apr 2013 if it is MM/DD. The other VeryGames files in the same repo cannot settle the format, because their dates are just as ambiguous (ex6tenz '09/08/2012', shox and lucas1 '08/12/2013'). Only the year is supported, so the date is now '2013'. Valve's CS:GO patch notes (ckreisl/cs-updates-as-json, crawled from Steam news) fit either reading. cl_crosshairgap was added on 22 Aug 2012, and de_dust2_se was added on 16 Mar 2012. cl_crosshairstyle 4 ('Classic Static') is named in the 5 Jun 2013 notes. The file does not contain cl_crosshair_drawoutline or cl_crosshair_outlinethickness, which were added on 22 May 2013. It aliases the community map de_mirage_csgo, not the official de_mirage, which Valve added on 12 Jun 2013. Nothing in the file postdates 2013. Where the file came from before 2016 is not recorded.
