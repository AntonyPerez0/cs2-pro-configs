  • Not in this config, so off, as CS:GO had it by default: cl_crosshairgap_useweaponvalue, cl_crosshair_t.
  • cl_crosshair_recoil was cheat-protected in CS:GO, so off.
  • Rounding and dropping the fraction give your old size or thickness different whole pixels; the converter rounds, as other converters and community measurements do, so the old game may have drawn it 1 px smaller.
  • Odd-width bars sit on a different centre pixel in the new game, so the crosshair may appear 1 px off.
  • Old thickness 0 still drew a thin line, so the export uses a positive thickness.

These are RpK's CS:GO settings from 2021-01-05, the closest to 2012 we found that can be converted (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 768p, RpK's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

Download .cfg

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec rpk-2012 in the console.

Where these settings come from

  • Crosshair · 2021-01-05 · confidence medium · github.com, liquipedia.net, params.gg
    How the date is known

    The Liquipedia RpK page says 'Updated as of 2021-01-05' on its mouse, hardware and crosshair tables, all citing params.gg/players/rpk (ref [2]). I read it from a cached copy, scraper-cache/players/rpk.html (zip entry dated 2023-10-22 19:30). The cache is inside scraper-cache.zip in github.com/Lindeneg/csgo-pro-settings (commit ddf05eb, 2023-10-26). The page shows '(1020 days ago)', and 2023-10-22 minus 1020 days is 2021-01-05, which checks out.

  • Sensitivity · 2016-12-13 · confidence low · github.com 1, 2
    How the date is known

    Git commit afdec47 ('Initial', 2016-12-13 17:37 +0200) in github.com/setupgg/data first added player/rpk/data.yml, and it is the file's only commit. It is a recording date: the file gives no date for when the settings were collected. The predecessor repo setupgg/csgo (23 commits, 2016-04-29 to 2016-12-14) has no RpK file. I checked every commit with git grep.
