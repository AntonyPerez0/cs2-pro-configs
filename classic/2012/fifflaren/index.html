#5 in Esports Earnings: top CS:GO prize-money earners of 2012 (Ninjas in Pyjamas). These are Fifflaren's CS:GO settings from 2012, the year of the ranking, with the resolution from 2014-06-12. Source confidence: medium.

The 'NiP Fifflaren' preset in Skarbo's third-party CS:GO crosshair generator (13 Dec 2012) has the same colour, size, thickness, gap and dot, with alpha 255 and style 2; that style has no basis in his own config, which has the dynamic crosshair off. His next dated configs use style 4: CSGO-Optimiser's 'fifflaren' profile, saved between August 2013 and January 2014 (size 3, thickness 0.5, gap -2, colour 4), and Liquipedia in November 2014 (size 3, thickness 0.5, gap 0, colour 4).

These are Fifflaren's CS:GO settings from 2012, the year of the ranking (see where these settings come from). Converted to CS2's crosshair system since the Sept 22, 2026 update, authored at 768p, Fifflaren's resolution; CS2 rescales it to your resolution.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922); for Static Cross at 1080p and 960p it agrees with the rule crosshairrestore.com measured from in-game screenshots (CS2 builds before Sept 30), and nothing else has been checked against captures.

The paste sets every setting that shapes this crosshair, including the iron-sight dot (CS2's defaults where their config has no value), so nothing from your current crosshair carries over.

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec fifflaren-2012 in the console.

Where these settings come from

  • Crosshair · 2012 · confidence medium · github.com 1, 2
    How the date is known

    Game-written config.cfg saved under the name 'NiP-Fifflaren-', published by setup.gg in 2016, the same file as the sensitivity. It has cl_crosshairgap (added 22 Aug 2012) but no cl_crosshairstyle, which Skarbo's generator already used on 13 Dec 2012, so it was most likely saved between those dates. Instead of a style it has sfcrosshair 0 (the classic crosshair) and cl_dynamiccrosshair 0 (no widening when moving); style 4 (Classic Static), the style of his next configs, is a mapping choice for that. Whether this crosshair still widened when firing is not documented.

  • Sensitivity · 2012 · confidence medium · github.com 1, 2
    How the date is known

    Game-written config.cfg saved under the name 'NiP-Fifflaren-', published by setup.gg in 2016. It has cl_crosshairgap (added 22 Aug 2012) but no cl_crosshairstyle, which Skarbo's generator already used on 13 Dec 2012, so it was most likely saved between those dates.

  • Resolution · 2014-06-12 · confidence low · github.com 1, 2
    How the date is known

    video.txt (1024x768, aspect ratio mode 0, i.e. 4:3) in the 'fifflaren' profile of CSGO-Optimiser, a third-party tool, added in its commit of 12 Jun 2014; the file has no date of its own, so that is only the latest it can be from. The same profile's game-written config.cfg ('NiP-Fifflaren- Telia') has a medal-stats timestamp of 24 Aug 2013 and lacks lobby_voice_chat_enabled (added 23 Jan 2014), so it was saved between those dates. setup.gg's player profile (created 13 Dec 2016, undated) also lists 1024x768 at 4:3. No source from 2012 gives his resolution.

  • DPI (assumed) · 2016-12-13 · github.com
    Why it is assumed

    No source lists a DPI with this sensitivity, so the DPI matcher assumes the 400 DPI of their setup.gg profile, which lists sensitivity 2.2; change it on the page if you know better.
