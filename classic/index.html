Classic configs. 2011–2015

The top 10 players of each year from 2011–2015, with their CS:GO settings converted for CS2: the crosshair converted to the new crosshair system, sensitivity, viewmodel and the rest as console commands. Each config is dated and sourced; when nothing from the exact time is documented (or it can't be converted), the closest one is used and its date shown.

2011 2012 2013 2014 2015

Rankings: HLTV's Top 20 Players of the Year (2011, 2013-2015) and Esports Earnings' 2012 CS:GO prize money. Configs come from public archives of pro CS:GO configs (mostly game-written config.cfg files in setup.gg's GitHub archive) and Liquipedia's settings tables. A date comes from the settings a file contains (checked against Valve's release notes), from a date written in the file or on its source (a header comment, Liquipedia's "Updated as of"), or else from the archive's commit date as an upper bound; each page lists its sources and how each date is known.
