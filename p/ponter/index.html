  • Odd-width bars sit on a different centre pixel in the new game, so the crosshair may appear 1 px off.
  • Old thickness 0 still drew a thin line, so the export uses a positive thickness.
  • Old outline thickness 0 drew no outline, so the export turns the outline off.

Converted from the pre-patch crosshair settings.gg lists for ponter to CS2's crosshair system since the Sept 22, 2026 update, authored at 1080p, ponter's resolution; CS2 rescales it to your resolution. Many pros rebuilt their crosshair after the update, so this may not be what ponter uses now — see their crosshair history.

Valve published no conversion formula. This uses a community reconstruction (small-indie-crosshair-company v0.19.1, model community-static-v11, CS2 build 2000922) that hasn't been checked against in-game captures.

The paste sets every setting that shapes this crosshair, including the iron-sight dot (CS2's defaults where their config has no value), so nothing from your current crosshair carries over.

The CS2 console can reject a pasted line longer than 510 characters, so the full config comes in parts: press ~ in CS2, paste part 1, press Enter, then do the same with the next part. Or download the .cfg, save it in Counter-Strike Global Offensive/game/csgo/cfg/ and run exec ponter in the console.
